Behind this clip

Docs · argus-mask on GitHub · Argus docs ·

Faces are generated characters, not real people: two built from CC0 MakeHuman assets, one a Gaussian-splat head made with LAM (non-commercial weights) from a portrait generated from text. Voices are XTTS-v2 studio speakers (Coqui Public Model License, non-commercial). Each clip's animation was made once, offline, and is replayed here. See the credits for every part and its licence.
